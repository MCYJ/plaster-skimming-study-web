# Plaster Skimming Study

Dedicated introduction and support website for the independent RushLabs app, GLB2623.

Static HTML/CSS/JavaScript, English default and Korean website copy. Use the language buttons or `?lang=ko`. App interface: English.

The site describes 500 retrieval tasks based on the retained 150 original study-anchor provenance. This is not a claim of 500 independent practical competencies. Original concept lessons use four-step process diagrams. The example uses the exact four labels from the first original concept lesson.

The real app icon is unchanged. Editorial content-overview and process diagrams are clearly labeled learning illustrations, not app screenshots. No native app UI is invented or shown.

The app is **coming soon**. One paid download is planned, with no subscription or additional in-app purchase. There are no download links or payment forms. Practical training, site-specific instruction, assessment, qualification award and official fees remain separate. No NOCN or government affiliation is claimed.

The app's currently registered privacy URI is retained. The dedicated support section links to the existing RushLabs app support page for this app. No account, tracking cookies, analytics or remote API is used by this static site.

Deploy the `main` branch root using static GitHub Pages (`legacy`), with `.nojekyll`. No custom GitHub Actions build workflow.

App icon: RushLabs. Inter and Libre Baskerville font licenses are retained in `assets/`.
