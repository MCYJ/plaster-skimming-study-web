미장 지식 · 독립적인 학습

주제를 이해하고, 꾸준히 복습해요.

석고 미장(plaster skimming)의 일부 주제를 공부하는 지식 연습입니다. 문제와 선택지를 살펴보고 해설을 다시 읽어 보세요.

학습 흐름 살펴보기

앱 학습 내용과 인터페이스는 영어입니다. 이 웹사이트는 5개 언어를 지원합니다.

읽고, 떠올리고, 다시 살펴보기.

서면 지식을 공부하는 도우미입니다. 현장에서의 실무 능력을 평가하지 않습니다.

문제 연습하기

준비 과정, 도구, 작업 방법과 마감 확인에 관한 일부 주제를 복습합니다.

해설 다시 읽기

선택지가 적절한 이유를 읽고, 필요할 때 같은 주제를 다시 살펴봅니다.

학습 기록 남기기

문제를 북마크하고 풀이 기록, 정답률과 저장된 문제를 내 기기에서 확인합니다.

4단계로 생각을 정리해요.

직접 만든 개념 수업에는 과정도가 포함됩니다. 이 예시는 학습 아이디어를 정리한 것이며 앱 화면이나 특정 현장의 작업 지침이 아닙니다.

  1. 현재의 현장 안내
  2. 작업 지침
  3. 변경된 조건
  4. 승인된 변경 사항
500개 연습 과제

일부 학습 주제를 반복해서 살펴보는 독립 학습 자료입니다. 공식 시험 문제은행이나 서로 다른 500개 실무 역량을 뜻하지 않습니다.

학습 기록은 내 기기에 남아요.

다운로드 후 내장 연습, 해설, 개념, 북마크와 학습 진도를 오프라인으로 이용할 수 있습니다. 다운로드·구매·업데이트와 외부 링크에는 인터넷 연결이 필요합니다.

시작하기 전에

실무 능력을 평가하나요?

아닙니다. 문제와 도식은 지식 학습을 돕습니다. 실기 훈련, 증빙과 공식 평가는 별도입니다.

지금 다운로드할 수 있나요?

출시 준비 중인 제품 소개입니다. 확인되지 않은 출시일이나 다운로드 링크는 제공하지 않습니다.

구독이 필요한가요?

한 번의 유료 다운로드로 준비하고 있습니다. 정기구독이나 추가 앱 내 구매는 필요하지 않습니다.
